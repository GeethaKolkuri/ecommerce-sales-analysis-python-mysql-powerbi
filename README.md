# 🛒 Ecommerce Sales Analysis – Python, MySQL & Power BI

## 📊 Project Overview

This is an end-to-end **Ecommerce Sales Analysis** project using **Python, MySQL, SQL, and Power BI**.

The project analyzes ecommerce sales data to understand sales performance, profit, orders, products, cities, payment modes, order status, and monthly sales trends.

Python is used for data exploration and preparation, MySQL is used for SQL-based business analysis, and Power BI is used to create an interactive sales dashboard.

## 🎯 Objectives

- Analyze ecommerce sales and profit performance.
- Explore and prepare the dataset using Python.
- Perform business analysis using MySQL and SQL.
- Identify top-performing products and cities.
- Analyze monthly sales trends.
- Analyze payment modes and order status.
- Build an interactive Power BI dashboard.
- Generate useful business insights.

## 🗂️ Dataset

The project uses:

`Ecommerce_Unclean_Project.xlsx`

The dataset contains ecommerce transaction data used for sales, profit, product, city, payment mode, order status, and monthly analysis.
